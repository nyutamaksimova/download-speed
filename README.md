# Download speed

Консольный скрипт на Python: выполняет 10 последовательных GET-запросов
по указанному URL, полностью читает каждый ответ и выводит среднее время
запроса, суммарный объём скачанных данных и скорость скачивания.

## Запуск

Нужен Python 3.10 или новее. Сторонние библиотеки не требуются.
Откройте терминал в папке проекта:

```bash
python download_speed.py "https://example.com/image.jpg"
```

Замените адрес на прямую ссылку на доступный файл. В Windows вместо `python`
можно использовать `py`, в macOS/Linux — `python3`.

Необязательная настройка таймаута:

```bash
python download_speed.py "https://example.com/image.jpg" --timeout 60
```

По умолчанию таймаут сетевой операции составляет 30 секунд. Это ограничение
ожидания отдельной операции с сокетом, а не всей загрузки.

Пример вывода (числа условные):

```text
Requests: 10
Average request time: 0.143 s
Total downloaded: 142530 bytes (0.136 MiB)
Download speed: 0.095 MiB/s
```

## Расчёты и единицы

- Время измеряется монотонным счётчиком `time.perf_counter()` от начала
  запроса до полного чтения тела ответа. Включает установку соединения,
  ожидание сервера и получение данных.
- Среднее время: сумма времени десяти запросов / 10, в секундах (`s`).
- Объём: сумма фактически прочитанных байтов тел всех десяти ответов.
  HTTP-заголовки и служебный сетевой трафик не учитываются.
- Скорость: общий объём / суммарное время запросов, в `MiB/s`.
  1 MiB = 1 048 576 байт. Это средняя скорость получения ресурса,
  зависящая также от сервера и задержек, а не только от интернет-канала.

Каждый следующий запрос начинается после полного чтения предыдущего.
Ответ читается блоками по 64 KiB и не сохраняется на диск, поэтому большой
файл не нужно целиком держать в памяти. Скрипт запрашивает несжатый ответ
(`Accept-Encoding: identity`); если сервер всё же присылает сжатые данные,
учитывается полученный размер без распаковки. HTTP-перенаправления
обрабатываются стандартной библиотекой; они могут добавлять сетевые запросы.

При HTTP-ошибке, сетевой ошибке или неполной загрузке скрипт прекращает
работу с кодом 1 и сообщением в stderr, без итоговой статистики по
незавершённой серии. Ошибки аргументов дают код 2. Успешный запуск — код 0.
Повторных попыток нет.

## Проверка

```bash
python -m unittest -v
```

Тесты запускают локальный HTTP-сервер; внешний интернет не нужен.
Проверяются десять полных загрузок, расчёты, HTTP-ошибка и проверка URL.
